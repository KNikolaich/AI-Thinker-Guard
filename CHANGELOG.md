# Changelog

## 1.4.0

- Веб-обновление прошивки: страница `/update` (выбор `.bin`, индикатор загрузки, проверка образа, автоматический перезапуск). Доступна, если в настройках разрешено обновление; защищена тем же логином `admin`.
- Внизу панели показана версия прошивки и ссылка «Обновить прошивку…».

## 1.3.2

- Пароль устройства проверяется одинаково на странице, в консоли и при загрузке: 8–63 печатных ASCII-символа (кириллица не принимается — она ломает WPA2 и Basic Auth).

## 1.3.1

- Точка настройки: проверки подключения Android/iOS/Windows получают абсолютное перенаправление на `http://192.168.4.1/`, поэтому телефон открывает окно «Вход в сеть» и не уходит на мобильные данные.
- Клиентам точки доступа с паролем Basic Auth не требуется (пароль уже введён при подключении); если точка открытая или вход из домашней сети — нужен логин `admin`.

## 1.3.0

- Пароль по умолчанию `Guard` + 5 цифр из MAC вместо случайного 20-символьного; печатается при каждой загрузке. Минимальная длина своего пароля — 8 (требование WPA2). Ранее сгенерированный случайный пароль заменяется паролем по умолчанию.
- При загрузке печатаются настройки (пароль Wi-Fi и токен — только признаком «задан»).
- Serial-консоль: эхо команд, приём команд во время ожидания Wi-Fi, новые команды `config`, `resetpassword`, `about`; `newpassword` удалена.

## 1.2.0

- Serial-консоль: `password`, `newpassword`, `setpassword`, `status`, `reboot`, `factoryreset yes` — восстановление доступа без перепрошивки.
- Исправлен `abort()` при `BLEDevice::init()`: при заданном MAC Wi-Fi работает с modem sleep (`WIFI_PS_NONE` + Bluetooth запрещено в ESP-IDF). BLE проверяет свободную RAM и результат инициализации, сканирует пассивно.
- Фото: камера переинициализируется в JPEG VGA (QVGA без PSRAM) и обратно в GRAYSCALE QQVGA. Раньше `set_pixformat()` на лету давал кадры не в JPEG, и снимки не отправлялись.
- Telegram: `WiFiClientSecure::setTimeout()` принимает секунды (было 15000 = ~4 часа), добавлен таймаут TLS-рукопожатия; разбор `getUpdates` с фильтром и пропуском «битого» обновления; сводка отложенных событий больше не повторяется каждую минуту; экспоненциальная пауза опроса без интернета.
- Wi-Fi: ожидание при старте 20 с, затем точка настройки с captive DNS; STA переподключается в фоне (пауза, пока к точке подключён клиент); точка выключается после 2 минут стабильного Wi-Fi и включается через 30 с после потери сети; OTA запускается при первом подключении, а не только при загрузке.
- `SystemHealth`: этап запуска в RTC-памяти, пропуск камеры/BLE после вызванного ими аварийного перезапуска, безопасный режим после 3 сбоев подряд, сброс блокировок при сохранении настроек/кнопкой.
- Страница настроек: блок «Состояние» и кнопка повторной инициализации модулей.
- NVS: восстановление повреждённого раздела; без NVS устройство работает на настройках по умолчанию вместо остановки. Ошибка сохранения пароля больше не блокирует сеть.
- Камера: повторная инициализация каждые 5 минут, обнаружение пропажи кадров. Watchdog основного цикла 90 с.

## 1.1.0

- Один случайный пароль устройства для AP и веб-панели; OTA по умолчанию выключена и использует тот же пароль после явного включения.
- Пустой токен/chat ID отключает Telegram без блокировки устройства; пустой/некорректный MAC отключает BLE.
- Ошибка инициализации камеры больше не блокирует Wi-Fi и веб-конфигурацию.
- Миграция старых настроек без автоматического включения OTA; добавлены этапные логи запуска.
